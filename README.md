## 📌 Project Overview
SafeHaven is a Java-based desktop application developed as part of an Object-Oriented Programming group project. The platform focuses on climate awareness, disaster preparedness, and community resilience by combining real-time information sharing with educational tools related to Sustainable Development Goal 13 (Climate Action). :contentReference[oaicite:0]{index=0}

The application allows users and administrators to share disaster-related posts, publish announcements, access emergency information, and calculate their carbon footprint through an interactive GUI built using Java Swing.

---

## 🎯 Project Objectives
- Promote awareness of climate-related hazards and natural disasters
- Encourage community engagement through information sharing
- Support SDG 13: Climate Action
- Improve preparedness and resilience during emergencies

---

## 🧠 Features Implemented

### 🔐 Authentication System
- User and Admin registration system
- Role-based login authentication
- Admin verification using admin codes
- Session handling and logout functionality :contentReference[oaicite:1]{index=1}

### 📢 Announcement Management
- Admin-exclusive announcement posting
- Delete announcement functionality
- Persistent announcement storage using file handling
- Dynamic announcement panel in the GUI :contentReference[oaicite:2]{index=2}

### 📝 Community Post System
- Share disaster-related posts
- View posts from other users
- Delete only user-owned posts
- File-based storage using `BufferedReader` and `BufferedWriter` :contentReference[oaicite:3]{index=3}

### 🆘 Disaster Helpline System
Provides emergency information and guidance for:
- Tsunamis
- Hurricanes
- Earthquakes
- Tornadoes
- Wildfires
- Floods
- Volcanic eruptions
- Blizzards

### 🌍 Carbon Footprint Calculator
- Calculates estimated CO₂ emissions
- Supports different fuel types
- Promotes environmental awareness and sustainable practices aligned with SDG 13 :contentReference[oaicite:5]{index=5}

2. Build the project
3. Run the main Java file
4. Register as either:
   - User
   - Admin (requires admin code)
